# Accessibility

The task scaffold uses semantic headings, labeled checkboxes, a skip link and visible focus. It has no automatic audio or animation. WCAG 2.2 AA is the target, not an audited compliance claim.

Participants must add labels, keyboard interaction, readable errors and text/table alternatives to the applications they build. Add pause/reset where needed and respect reduced-motion preferences. Check at 200% zoom and a narrow viewport. Test one screen-reader path manually and record browser, device and observations before the event. Real browser and assistive-technology validation remain pending.
