# RISE Agentic Hackathon

Five tasks for building an interactive application with a coding agent in 30–60 minutes. Pick a mission, describe a small outcome, build it, check it and explain your evidence. All inputs are synthetic. No RISE endorsement is implied.

| Task | Build |
| --- | --- |
| [Data Detective](challenges/01-data-detective/README.md) | A sensor dashboard and evidence-based observation |
| [Robot Lab](challenges/02-robot-lab/README.md) | A two-link arm simulator |
| [Mini Factory](challenges/03-mini-factory/README.md) | A production-line simulation |
| [Sound Lab](challenges/04-sound-lab/README.md) | A visual sound analyzer |
| [Research Autopilot](challenges/05-research-autopilot/README.md) | A reproducible experiment and report |

Each task includes inputs, steps, prompts, acceptance criteria and an empty application workspace. Participants implement the UI and logic. No completed applications, answer key or solution-import shortcuts are included.

In a prepared cloud workspace: `npm ci`, then `npm run dev`; open private port 5173. Node 24.22.0 is pinned. [Getting started](GETTING_STARTED.md) · [Agent workflow](docs/AGENT_WORKFLOW.md) · [Fallbacks](docs/FALLBACKS.md).

An approved browser, eligible GitHub account and permitted Codespaces access are needed for the cloud route. Identify the payer before creating compute; quotas, retained storage and separate agent entitlement apply. No paid API is required by the tasks. Remote template/launch and event timings remain unverified. [Release checks](docs/RELEASE_CHECKLIST.md).

The offline ZIP contains task pages, worksheets and inputs. Viewing the brief needs no installation; building code needs an already approved editor or pairing. Code is licensed MIT (see LICENSE); synthetic data is CC0.
