# Task-kit handover

The active project now contains five task briefs, synthetic inputs, prompts, acceptance checklists and minimal empty application workspaces. Participants build the functionality themselves. Completed applications, shared model implementations, answer key and one-line solution imports have been removed from the active source.

Run npm ci then npm run dev in a prepared workspace. The participant artifact is artifacts/offline-kit.zip. Production output is dist. Neither package includes completed applications.

The previous implementation is preserved only in historical local archives under artifacts/milestones, which are ignored and excluded from participant builds. Do not distribute those old archives as the new task kit.

See docs/VERIFICATION.md for test scope and docs/RELEASE_CHECKLIST.md for remaining owner, browser, Codespaces and pilot checks. No remote PR, merge, publication or billing change occurred.
