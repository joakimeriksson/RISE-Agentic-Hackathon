# Preflight

**One week before:** confirm owner/organization approval, license/branding decisions, eligible individual accounts, payer, quotas and actual budget blocking. Verify agent entitlement and its workspace connection. Test one real managed laptop on the event network. Check domains, private forwarded preview sign-in, supported browsers, accessibility needs and account restrictions. Pilot each challenge with a beginner; record times and revise scope.

**One day before:** create a fresh Codespace from a participant-owned template copy; record cold-start time, machine size and network. Verify npm ci, Run demo, private port 5173, external browser preview, save/push/download and stop/delete. Test no agent, denied microphone, blocked Codespaces and the actual extracted offline ZIP with network disconnected. Recheck distribution links and prepare a second facilitator/device.

**30 minutes before:** recheck quota and account access, copy the offline ZIP to an approved distribution channel, open task pages, check projector zoom and keyboard access, announce the private support contact and fallback ladder. Confirm attendees know who pays and how to stop/delete compute.

No real managed-device, Codespaces or beginner pilot has been performed by this implementation session. These checks remain assigned to the event facilitator; they are not replaced by automated browser tests.
